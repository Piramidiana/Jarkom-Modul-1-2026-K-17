# Pengumpulan Sementara Modul 1 – K-17

## Isi Pengumpulan

1. `01_Project_GNS3` berisi portable project hasil export langsung dari GNS3.
2. `02_Scripts_Per_Soal` berisi perintah CLI yang dikelompokkan berdasarkan nomor soal dan node tempat perintah dijalankan.
3. `03_Captures` berisi capture yang digunakan sebagai bukti atau bahan analisis.
4. `04_Dokumentasi` berisi laporan sementara dan screenshot yang tersedia.
5. `05_File_Pendukung` berisi file yang digunakan dalam pengujian FTP.
